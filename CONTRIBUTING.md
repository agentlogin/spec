# Contributing

- Editorial fixes: open a pull request.
- Behavioural changes: open an issue first, describe the problem an implementer hit, then a pull request.
- Implementer reports: open an issue titled `Report: <implementation> vs draft 0.x` with the conformance
  checklist results.

## Style

Normative language follows RFC 2119 and RFC 8174. Keep sections short; put detail in tables and examples; cite
existing standards rather than restating them.
